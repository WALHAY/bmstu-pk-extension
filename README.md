# AI Warning

# Описание

Добавляет несколько весьма полезных QoL фич для работы с сайтом приемки и сайтом обзвона абитуры.

# Фичи

- добавляет кнопку "позвонить" на сайте приемки
- глушит вкладку звонка во время вызова абонента
- возвращает звук вкладки звонка во время соединения с абитурой
- глушит вкладки Яндекс Музыки во время соединения с абитурой
- присылает уведомление о соединении с абитурой
- всплывающее меню настроек расширения с переключателями
- добавляет опции быстрого ответа в drop-down меню комментариев

# Поддерживаемые браузеры

- Chrome
- Yandex (не тестировал)

# Установка

1. зайти во вкладку с расширениями
2. активировать флажок «Режим разработчика»
3. скачать и распаковать архив данного репозитория
4. загрузить распакованное расширение
