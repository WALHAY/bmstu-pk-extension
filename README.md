# Описание

Добавляет несколько весьма полезных QoL фич для работы с сайтом приемки и сайтом обзвона абитуры.

# Фичи

- кнопка позвонить на сайте приемки
- мут вкладки звонка во время вызова абонента
- размут вкладки звонка во время соединения с абитурй
- мут вкладки яндекс музыки во время соединения с абитурой
- присылает уведомление о соединении с собесдником
- всплывающее меню настроек расширения с переключателями:
  - глушить/не глушить Яндекс Музыку во время разговора
  - глушить/не глушить вкладку звонка во время дозвона (Provisioned)
  - включить/выключить уведомление после соединения с собеседником

# Поддерживаемые браузеры

- Chrome
- Yandex (не протестировано)
